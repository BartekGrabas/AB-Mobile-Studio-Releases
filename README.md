# AB Mobile Studio Releases

Publiczne repozytorium oficjalnych wydań AB Mobile Studio.

Repozytorium służy wyłącznie do dystrybucji zatwierdzonych APK, GitHub Releases i informacji o najnowszej wersji. Nie umieszczamy tu kodu źródłowego aplikacji, tokenów, keystore ani danych użytkowników.

Aktualizacje aplikacji będą korzystać z pliku `latest.json`. Do czasu przygotowania pierwszego podpisanego APK plik nie wskazuje żadnego artefaktu.
